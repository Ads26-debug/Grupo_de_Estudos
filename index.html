Teste de visualização realizado no grupo de estudos do curso de desenvolvimento web da Alura. O objetivo é criar um site simples utilizando HTML e CSS para praticar as habilidades adquiridas durante o curso. Este projeto é uma oportunidade para os participantes aplicarem seus conhecimentos e compartilharem suas criações com o grupo, promovendo a colaboração e o aprendizado mútuo. Site de estudos dos alunos de ADS Anhanguera de Sertãozinho
